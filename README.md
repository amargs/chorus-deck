# chorus-deck
Tool to generate slide decks with church songs and responses

## Milestones

1. Parse source ppt file and output song titles ✅
2. Index songs by title ✅
3. Generate ppt file with selected songs
4. Add appropriate template to slides
5. Retrieve song number from document
6. Add response slides
7. Response slides according to liturgical season
8. Add UI
9. Tag songs with additional info (e.g: moment, liturgical season, difficulty level, children's song, etc)
10. Allow selecting songs per correct moment
11. Fetch liturgy from the web according to Sunday and add to deck
12. Keep history of past song choices to not repeat acrosss weekends
13. Use liturgical info to suggest appropriate songs
14. Detect changes on source file
